# Reference inputs

The current default is `inputs/reference_raw` (plural `inputs`). This legacy
directory is still usable with explicit `--reference-raw input/reference_raw`.
See ../../../README/EVOLUTIONARY_BENCHMARKING.md for the automatic benchmark
Input/RefOGs layout and default-disabled phylogeny.

Place complete reference protein FASTAs here: `Code.fa`, `Code.faa` or
`Code.fasta` (optionally gzip-compressed). Supply matching `Code.gff`/`Code.gff3`
with NCBI CDS protein_id/GeneID annotations, or `Code.protein_gene.tsv` containing
protein_id and gene_id columns. Explicit gene= fields or already prepared
Code__gene_id FASTA headers can be used without a sidecar.

Run resume from the package root. References, mappings and the OrthoFinder panel
are prepared automatically. See ../../ORTHOLOGY_PHYLOGENY_GUIDE.md.

An optional targeted human panel is bundled at
`../../01_detection/references/adhesome_v1.0/HsaAdhesomeReferencePanel.faa`.
It covers the 230 crosswalk components and existing human ECM/family references
(242 unique accessions). Copy it and its generated `.reference.json` sidecar here only when intentionally using a targeted
panel; its gene= headers require no GFF or gene-map sidecar. The scope JSON is generated by the builder and requires no manual editing. It is not a complete proteome and
should not duplicate a human taxon already supplied as a complete proteome.
See ../../../README/COMPONENT_REFERENCE_PANEL.md for detection refresh and calibration.
